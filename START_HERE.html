A short guide to opening the app, signing in, enabling Google login, and keeping your data synced.

Made by serif xvi

01 · Open MoneyMap

  1. Extract the ZIP file to a normal folder. Do not run it from inside the ZIP.
  2. Open the extracted MoneyMap folder.
  3. Double-click start-moneymap.bat.
  4. Enter your OpenAI API key in the hidden PowerShell prompt, then press Enter.
  5. Wait for the browser to open. Keep the PowerShell window running while you use MoneyMap.
MoneyMap → start-moneymap.bat
Do not open index.html directly. Use the BAT launcher. To stop MoneyMap, click the PowerShell window and press Ctrl+C.

02 · Create your MoneyMap account

  1. Open the account section in MoneyMap.
  2. Enter your email address and choose a password of at least 8 characters.
  3. Click Create account.
  4. If email confirmation is requested, open the message and verify your address.
  5. Return to MoneyMap and click Sign in.
The app is preconfigured. You do not need to enter a Supabase URL, API key, or create a Supabase project.

03 · Enable Google sign-in (one time)

Google login needs a Google OAuth Client ID and Client Secret connected to Supabase. The app cannot create these credentials for you.

A. Create Google OAuth credentials

  1. Open Google Cloud Console and create/select a project.
  2. Open Google Auth Platform. Configure the app name, support email and audience. If it is in Testing mode, add your Google account as a test user.
  3. Go to Clients → Create client → Web application.
  4. Under Authorized JavaScript origins, add the local MoneyMap origin printed in PowerShell, e.g. http://127.0.0.1:8785 (use your actual port).
  5. Under Authorized redirect URIs, add the Supabase callback URL shown on Supabase's Google provider page. It usually looks like https://YOUR-PROJECT-REF.supabase.co/auth/v1/callback.
  6. Create the client and copy its Client ID and Client Secret.

B. Enable Google in Supabase

  1. In Supabase Dashboard, open Authentication → Sign In / Providers → Google.
  2. Enable Google and paste the Google Client ID and Client Secret. Save.
  3. Open Authentication → URL Configuration. Add the exact MoneyMap local URL printed in PowerShell to the Redirect URLs allow list, e.g. http://127.0.0.1:8785/.
  4. Save. Return to MoneyMap and click Continue with Google.
The Google Client Secret belongs only in Supabase's Google provider settings. Never paste it into MoneyMap or send it in chat.

04 · Sync and AI

  1. After signing in, MoneyMap checks for a cloud backup. If local and cloud data both exist, read the prompt carefully and choose which copy to keep.
  2. Use Sync now for an immediate cloud save. Your profile, budget, weekly transactions, notes and AI chat history are included in the account backup.
  3. AI Coach uses a separate OpenAI API key entered when the PowerShell server starts. It is not your Google password or Supabase key.
