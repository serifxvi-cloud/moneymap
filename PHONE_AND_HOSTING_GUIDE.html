Use MoneyMap on your phone — no ZIP extraction

MoneyMap is now prepared as an installable web app (PWA). Once it is published online, users open one website link and can add it to their phone's home screen. They do not download or extract the project ZIP.

One-time publishing by the owner

  1. Extract the MoneyMap folder on a computer.
  2. Create a private GitHub repository and upload the contents of the MoneyMap folder (make sure app.py, index.html, requirements.txt, render.yaml and service-worker.js are at the repository root).
  3. In Render, choose New → Blueprint, connect that repository, and deploy the render.yaml blueprint.
  4. In the Render service's Environment settings, add OPENAI_API_KEY with the owner's OpenAI API key. Never put this secret in HTML, GitHub, or send it to users. The default model is gpt-4.1-mini; change OPENAI_MODEL only if the owner's API account has access to another model.
  5. Copy the HTTPS address Render gives the app, for example https://your-moneymap.onrender.com.
  6. In Supabase → Authentication → URL Configuration, set the Site URL to the Render HTTPS address and add that same address (and any custom domain) to the Redirect URLs. The app already contains the public project URL/key; users do not enter Supabase settings. Keep the existing database table and Row Level Security setup from MONEYMAP_CLOUD_SETUP.sql.

Install on iPhone

  1. Open the published HTTPS MoneyMap link in Safari.
  2. Tap Share (square with arrow).
  3. Choose Add to Home Screen, then tap Add.
  4. Open MoneyMap from its new home-screen icon.

Install on Android

  1. Open the published HTTPS MoneyMap link in Chrome.
  2. Tap the browser menu (⋮), then Install app or Add to Home screen.
  3. Confirm the install. MoneyMap appears with the other apps.
Important: This ZIP prepares the app for online hosting; it does not itself publish a public website. Publishing is a one-time owner task. Render's free service may sleep when idle and take a little time to wake. Live AI, market quotes, and translation need an internet connection. The app shell can be cached, but finance data should be synced to an account to move between devices. Do not use the PWA offline as a guarantee of cloud backup.

For visitors

After the owner publishes it, visitors only need the website link. They can create/sign in to their MoneyMap email account and add the app to their phone. No ZIP, extraction, npm, or Supabase dashboard access is needed for visitors.
